Notes

H = Vout/Vsrc with the source impedance and the chosen load (default: converter side open), as in the NP-DR reports. Because the network is reciprocal, |Hopen| also equals the ratio of source ripple current to converter ripple current. S21 is the 50 Ω two-port S21 of the filter blocks only (no source impedance), as a VNA measures it.

Qeff = peak|Zout| / Z0, with Z0 = √(L/C) of the series element nearest the converter and the capacitors after it. Rd for Q uses Rd = Z0²/(Z0/Q − rL) (NP-DR-26001 eq. for the Rd-Cd leg). Optimum Rd searches Rd for the lowest peak |Zout| with every parasitic included. The closed-form optimum (lossless L and C) for Rd-Cd, parallel Rd-Ld and series Rd‖Ld follows Middlebrook and Erickson; this tool checked each one against its own numeric optimizer for n = 0.1 to 4.

Ripple: the converter input current harmonic at N·fsw is 2·Io·|sin(NπD)|/(Nπ) (peak, ideal trapezoid, N interleaved phases, D = Vout/(Vin,nom·η)). Block losses at that frequency use this one harmonic only.
