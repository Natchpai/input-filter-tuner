# Bug fixes, 2026-11-04

Found by a review of the engine, the state and save/load code, and the UI,
plots and export. Each line: the bug, the fix, and the test.

## Engine

- Plot zoom changed the stability verdict: `checkRange` used the plot
  f max and f min. Now min(f min, 10 Hz) to fcheck.
  `regressions.test.ts` "check range".
- Vin fields out of order judged the margin at the typed "Vin min". Now
  the lowest Vin (`vinLow`) for |Rn| min, Iin and Tm. `regressions.test.ts`.
- Light load above full load made a heavier "light" corner. `corners()`
  uses min(pLight, pout). `regressions.test.ts`.
- The peak could land just above fcheck (D1 Method B, fcheck 0.995 × the
  peak). The refine window is clamped. `regressions.test.ts`.
- `primary()` returned none when a bead sat at the converter with no cap
  after it. It now tries the next inductive block. `regressions.test.ts`.
- EMI: a corner with Vout ≥ Vin·η (LQRx 03 at 9.39 V) dropped out with no
  word. `EmiResult.dropout` lists it; the card and report say so.
  `regressions.test.ts`, browser check.
- EMI: the worst corner was matched by label (12 V and 12.001 V share
  one). Rows keep the corner index. `regressions.test.ts`.

## State and save/load

- Undo could leave the EMI tab selected with EMI off. `keepView` falls
  back to Zout. `history.test.ts`.
- EMI edge time above 1 µs was stored, then cut on reload. The reducer
  clamps tr and margin like `adopt()`. `reducer.test.ts`.
- `adopt()` threw on object values with a bad `toString`, and fmin 1e308
  gave fmax ∞. Objects fall back to defaults; plot range and block count
  (64) are capped. `adopt.test.ts`.
- Block names over 40 characters were cut on reload. The input has
  `maxLength` 40 and `dup` keeps 40. `reducer.test.ts`.
- The curve editor showed points with 3 digits, so an edit could round or
  drop points. It now keeps 6. `curve-text.test.ts`.
- "12,5 3,96" read as 12 and 53. `parseSI` allows a space only before a
  prefix or unit, so this line now shows an error. `si.test.ts`,
  `curve-text.test.ts`.
- An unreadable saved-designs list was overwritten by the next save. It is
  first copied to `input-filter-tuner-designs-v1.bak`; a bad item name or
  time no longer throws. `library.test.ts`.
- A design link was lost on a reload before any edit. It is saved at once;
  `%3D` in the hash is decoded. Browser check.
- Compare did not show Vout or light-load differences. `compare.test.ts`.

## UI, plots and export

- A `"` in a name showed as `&quot;` in plots. `esc()` uses `&#34;`.
  `traces.test.ts`.
- A `|` in a block name split the report's cover specs. It becomes `/`
  there. `report.test.ts`.
- Note lines starting with `$$`, `![`, `|` or `>` could stop the report
  build or turn into a table or note box. They are escaped.
  `report.test.ts`.
- "Attenuation" was negative in Results, Compare and the report, positive
  in Corners. It is positive everywhere; |H| stays a gain and says
  "converter side open". `report.test.ts`.
- View settings marked a tolerance run stale. The key holds only what the
  run uses. Browser check.
- The report dialog said four figures; the report Zout figure had no
  worst-corner curve. Both fixed.

Not fixed (low value): a theoretical grid miss in `peakZout` for a
zero/pole pair inside one grid step, ZinOpen = NaN with no shunt part, and
the no-op undo step from a quick on/off toggle.
